## Highest-signal findings (all CONFIRMED with quoted code)
1. E-LIMIT regex runs over the model's own successful output in three places — a lesson
   mentioning "rate limit" poison-pills the distill queue; a security stage recommending
   rate-limiting halts the autopilot; a real limit mid-batch in curateStaged bypasses the
   canary gate + events + commit and exits 2 instead of 4.
2. "A headline is never repeated in one session" is a -10 penalty, not a filter — a
   3-keyword lesson re-fires every prompt; threshold 4.0 is reachable with zero trigger
   hits (stack 3.0 + prior 1.0).
3. 7 of 9 eval scenario checkers report task_complete for a do-nothing agent (fixture
   TODOs satisfy the regexes); S08's catch signal keys on the injected lesson's own
   vocabulary; Wilson CIs computed but never printed; 3 of 6 canaries never execute.
4. fetch.js has no SSRF defense (redirect-to-loopback / private-IP https is followed).
5. Atlas cache keyed by directory basename — two projects named "app" silently serve each
   other's graphs into agent context.
6. A corrupt academy state.json is silently replaced with a blank one (checkpoint loss).
7. ~340ms of every hook fire is avoidable ajv import/compile (~70% of measured latency);
   ARCHITECTURE.md promises a latency self-disable + latency_ms that were never built.
8. 18.7 skill lint and 18.10 effort router have NO production callers — recorded shipped
   in session 15, reachable only from their own tests. Reported plainly as our own miss.
9. curator .join() on counter_indications (a string) — no candidate carrying the field
   can ever machine-activate; the fail-closed catch masked it as "reviewer call failed".
